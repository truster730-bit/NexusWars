# Nexus Wars

This project is intentionally structured in stages to keep the scope manageable.

## Current repository structure

- `README.md` — overall project overview
- `docs/` — design, roadmap, architecture
- `project/` — Godot client project
- `server/` — multiplayer server prototype
- `art/` — future art/visual references
- `tools/` — future utility scripts

## Purpose

The goal is to build a playable prototype before expanding the project into a bigger open-world multiplayer game.

## Development priority order

1. Player movement
2. Combat and hit detection
3. Resource collection
4. Base construction prototype
5. Multiplayer room sync
6. Mobile optimization
7. Expanded world and content

## Next action

The next step will be to create the first playable Godot scene and a minimal multiplayer handshake between client and server.
